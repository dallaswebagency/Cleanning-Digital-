# CleaningDigital website

Static multi-page HTML site for CleaningDigital, built to the CleaningDigital Brand and Website Guidelines (25 Oct 2026).

Pages: index, services, industries, projects, reviews, pricing, about, contact, privacy, blog and 3 blog posts.
Shared files live in `assets/` (style.css, main.js, logo files, favicon).

Before launch, review:
- reviews.html: placeholder cards, replace with verified client reviews
- projects.html: designs are labelled as concepts, add verified outcomes when available
- pricing.html: starting prices are sample figures, confirm before going live
- contact.html and the homepage form: front-end demo only, connect to your form handler or CRM
- privacy.html: draft text, have it reviewed and add registered business details
- Email is set to hello@cleaningdigital.com, change if different
