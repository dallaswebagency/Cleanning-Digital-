# CleaningDigital website

Static multi-page HTML site for CleaningDigital (web design and digital marketing for cleaning companies, USA and Canada).

Pages: index, services, industries, projects, reviews, pricing, about, contact, blog and 3 blog posts.
Shared files live in `assets/` (style.css, main.js, logo files).

Before launch, review:
- reviews.html: placeholder cards, replace with real client reviews
- pricing.html: starting prices are sample figures, confirm before going live
- contact.html: the form is a front-end demo, connect it to your form handler or CRM
- Email is set to hello@cleaningdigital.com, change if different
